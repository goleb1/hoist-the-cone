# Hoist the Cone

The unofficial Buccos traffic report.

A polished one-page fan dashboard that translates live/recent Pirates baseball into a deeply unofficial Cone Index, traffic report, and recent hoist ledger. Data comes from the public MLB Stats API.

## Local development

```bash
npm install
npm run dev
```

## Quality gates

```bash
npm run lint
npm run build
```

## Notes

Unofficial fan project. Not affiliated with MLB or the Pittsburgh Pirates. Acquire cones legally.
